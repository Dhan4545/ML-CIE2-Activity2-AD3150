Title

Simple House Price Prediction using Linear Regression

Objective

To build a Simple Linear Regression model to predict house prices using a numerical feature and evaluate its performance.

Dataset

- Dataset Name: California Housing Dataset
- Source: Scikit-learn
- Dataset Link: https://scikit-learn.org/stable/datasets/real_world.html#california-housing-dataset

Features Used

- Input Feature (X): MedInc (Median Income)
- Target Variable (y): MedHouseVal (Median House Value)

Algorithm

Simple Linear Regression

Steps Performed

1. Imported the required Python libraries.
2. Loaded and explored the California Housing dataset.
3. Checked the dataset shape, columns, data types and summary statistics.
4. Selected MedInc as the input feature and MedHouseVal as the target.
5. Visualized the relationship using a scatter plot.
6. Split the dataset into 80% training data and 20% testing data.
7. Trained the Linear Regression model.
8. Predicted house prices using the test data.
9. Evaluated the model using MAE, MSE and R² score.
10. Compared actual and predicted values using a visualization.
11. Predicted the house value for a new input.
